# Vision V4

Real-time Android object detection built with **CameraX + NCNN + YOLO26**.

## Features

- Real-time object detection
- Fully offline (on-device inference)
- CameraX live camera pipeline
- Native C++ inference with JNI
- Jetpack Compose UI

## Tech Stack

- Kotlin
- Jetpack Compose
- CameraX
- C++
- JNI
- Tencent NCNN
- OpenCV Mobile
